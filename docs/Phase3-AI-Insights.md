Phase 3 Prompt

Objective

Introduce an AI Insight Layer that consumes deterministic assessment results and generates:

executive summaries
business-friendly explanations
modernization narratives
risk analyses
remediation plans
architecture Q&A

The deterministic engine remains the system of record.

AI should never calculate scores.

AI should explain and contextualize scores.

Core Design Principle

The system must distinguish:

Facts

Generated by deterministic engines.

Example:

{
  "score": 48,
  "findings": [
    {
      "severity": "High",
      "title": "Legacy Framework"
    }
  ]
}


These are authoritative.

Insights

Generated by AI.

Example:

The organization faces increased modernization risk because critical workloads remain on unsupported frameworks that may limit security patching and cloud migration opportunities.


AI may explain.

AI may not alter facts.

Prompt Strategy

Never send raw uploaded artifacts.

Send structured assessment data.

Example payload:

{
  "assessmentType": "Modernization",
  "score": 48,
  "recommendation": "Refactor",
  "findings": [
    {
      "severity": "Critical",
      "title": "Unsupported SQL Server"
    },
    {
      "severity": "High",
      "title": "Legacy Framework"
    }
  ]
}


This keeps token usage low.
